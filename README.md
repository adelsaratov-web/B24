# Рабочий стол диспетчера ВДГО

Локальное приложение Bitrix24 для диспетчеров ООО «Покровсктрансгаз».

## Реализовано

- загрузка рабочих сделок воронки ВДГО (`CATEGORY_ID=27`);
- поиск по клиенту, телефону, адресу и ID;
- очереди по стадиям и KPI;
- карточка клиента и объекта;
- назначение выезда;
- фиксация перезвона и недозвона;
- закрытие ТО как выполненного;
- печать заказ-наряда;
- установка пункта в левое меню через `placement.bind`;
- демонстрационный режим вне Bitrix24.

## URL приложения

`https://adelsaratov-web.github.io/B24/`

## Подключение в Bitrix24

1. Открыть **Разработчикам → Другое → Локальное приложение**.
2. Создать локальное приложение с URL обработчика `https://adelsaratov-web.github.io/B24/`.
3. Выдать права `crm`, `user`, `placement`.
4. Открыть приложение от администратора.
5. Нажать **Установить в меню**.

Входящий вебхук позволяет работать с CRM, но не может зарегистрировать `placement`: для встройки необходим контекст локального приложения/OAuth.
